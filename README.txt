ПОРТФОЛИО ШОХРОЗЫ — «Pink Web Site»
========================================

КАК ОТКРЫТЬ
----------
Дважды кликни по файлу  index.html  — и всё.
(Или запусти  start.bat — он откроет сайт в браузере.)
Установка не нужна. Интернет нужен только для шрифтов Google Fonts
(если нет интернета, подставятся системные шрифты — сайт всё равно работает).


ЧТО ВНУТРИ
----------
• 3D-сцена (Three.js) на ГОТОВЫХ моделях: танцующий персонаж
  (робот с настоящей анимацией Dance), волейбольный мяч, микрофон
  на стойке, парящие ноты и искорки. Всё на WebGL.
• Портфолио: Обо мне • Танцы • Музыка • Волейбол • Игра • Контакты.
• Мини-игра «Танцевальный чек»: 4 дорожки, стрелки ← ↑ ↓ →,
  3 этапа (108 / 126 / 142 BPM), комбо, жизни, точность.
• Музыка синтезируется прямо в браузере (WebAudio) — mp3-файлов нет.
• 3 темы: розовая (по умолчанию), чёрная, белая. Переключатель
  в правом верхнем углу. Выбранная тема запоминается в браузере.


3D-МОДЕЛИ И ЛИЦЕНЗИИ
--------------------
models/robot.glb        RobotExpressive — Tomas Laulhe (Quaternius), CC0 1.0
                        (пример из three.js, 14 анимаций, есть Dance)
models/volleyball.glb   Volleyball by jeremy, poly.pizza — CC-BY 4.0

Все модели вшиты прямо в js/bundle.js, интернет для 3D не нужен.


СТРУКТУРА ФАЙЛОВ
----------------
index.html            разметка всех экранов
css/style.css         стили, 3 темы, все анимации
js/bundle.js          готовый скрипт (его подключает index.html)
js/main.js            вход: темы, курсор, 3D, игра
js/scene3d.js         загрузка готовых моделей и их анимация
js/game.js            мини-игра «Танцевальный чек»
js/audio.js          синтезатор музыки и звуков
models/*.glb          готовые 3D-модели (вшиты в bundle при сборке)
vendor/three.module.js  библиотека Three.js (нужна только для сборки из исходников)
vendor/jsm/            загрузчик glTF (GLTFLoader) — тоже только для сборки
start.bat             ярлык для запуска


КАК МЕНЯТЬ
----------
• Имя, тексты — в index.html.
• Цвета тем — в начале css/style.css (--p1, --p2, --ink и т.д.).
• Музыка/ритм игры — js/audio.js (методы popStep и danceStep).
• Сложность игры — массив STAGES в начале js/game.js.
• Ссылки на соцсети — раздел «Напиши мне» в index.html.


ПЕРЕСБОРКА (если правил js/*.js вручную)
-----------------------------------------
Нужен Node.js. В папке сайта выполни:

  npx --yes esbuild@0.24.0 "js\main.js" --bundle --format=iife --target=es2019 ^
      --loader:.glb=binary --alias:three=./vendor/three.module.js ^
      --outfile="js\bundle.js"

(флаг --loader:.glb=binary вшивает модели внутрь bundle,
 --alias:three говорит esbuild, где лежит Three.js)


ЕСЛИ ЧТО-ТО ПОЛОСАЛОСЬ
----------------------
• Нет звука — нажми в любом месте страницы один раз,
  браузер не даёт включать звук без первого клика.
• Чёрный экран вместо 3D — обнови браузер до последней версии
  (нужен WebGL2). Остальной сайт всё равно работает.
• Правильный код без ошибок проверен в Chrome и Edge.
